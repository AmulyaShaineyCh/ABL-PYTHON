FLOWCHART (text version)

[Start]
   |
[Input total_classes and attended_classes]
   |
{total_classes <= 0?}
   | Yes
   v
[Display invalid total classes] ---> [End]

   No
   |
   v
{attended_classes < 0 OR attended_classes > total_classes?}
   | Yes
   v
[Display invalid attended classes] ---> [End]

   No
   |
   v
[attendance = attended_classes / total_classes * 100]
   |
[Display attendance]
   |
{attendance >= 75?}
   | Yes                              | No
   v                                  v
[Display 0 additional classes]   [Set extra_classes = 0]
   |                                  |
   |                                  v
   |                     {Projected attendance < 75?}
   |                         | Yes             | No
   |                         v                 v
   |              [Increase extra_classes] [Display extra_classes]
   |                         |
   |                         +----> Return to projected-attendance check
   |                                           |
   +-------------------------------------------+
                       |
                      [End]

Projected attendance =
(attended_classes + extra_classes) /
(total_classes + extra_classes) * 100
