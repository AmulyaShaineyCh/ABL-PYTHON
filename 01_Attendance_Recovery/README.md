# Case Study 12: Attendance Recovery Computation

## Problem
Calculate a student's current attendance percentage and find the minimum number of consecutive future classes the student must attend to reach 75% attendance.

## Python concepts used
- Variables and integer conversion
- `input()` and `print()`
- Arithmetic and relational operators
- `if`, `elif`, and `else`
- `while` loop

The program uses concepts listed in the supplied Units I–III syllabus.

## Run
Run `main.py` with Python 3. Enter the total classes held and classes attended when prompted.
