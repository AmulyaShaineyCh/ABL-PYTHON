Algorithm

1. Start.
2. Input the text string.
3. If the string is empty, handle it according to the program's logic.
4. Set the current character to the first character and its count to one.
5. Scan the remaining characters one by one.
6. If a character matches the current character, increase the count.
7. Otherwise, append the current character and count to the result, then start a new run.
8. After the loop, append the final character and count.
9. Display the compressed string.
10. Stop.
